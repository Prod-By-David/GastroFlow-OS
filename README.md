# 🍽️ GastroFlow OS

Sistema operativo de hostelería de ultra baja latencia optimizado para la gestión inteligente de salones, comandas en tiempo real y pantallas KDS para cocina.

## 🚀 Características Principales
- **Arquitectura Modular:** Desarrollado bajo principios SOLID y tipado estricto con TypeScript.
- **Mapa de Salón Interactivo:** Control visual instantáneo de mesas libres y ocupadas por zonas.
- **Kitchen Display System (KDS):** Sincronización automática de comandas hacia cocina con temporizadores.
- **Panel de Configuración CRUD:** Personalización total de zonas, mesas y carta del restaurante guardado localmente mediante `localStorage`.

## 🛠️ Stack Tecnológico
- **Framework:** Next.js 14+ (App Router)
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS
- **Iconografía:** Lucide React

## 📦 Puesta en Marcha
1. Instala las dependencias:
   ```bash
   npm install
   ```
2. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
3. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
